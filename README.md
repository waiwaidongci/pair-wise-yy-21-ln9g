# 船舶配载图与稳性校核编辑器

基于 React、Blueprint、Redux Toolkit 和 Canvas 的船舶配载工具。支持按重量与目的港分配格位、**贝位冷藏箱供电插口配载（插口容量/检修停用、按卸货港排队、腾退后队头自动补进低层格位）**、危险品隔离校核、吃水/横倾/纵倾和 GM 的**增量重算**、多方案对比、撤销重做、**操作号幂等与写盘失败按操作号退避重试**，以及配载图和带插口占用/待供电明细的配载清单导出。

## 冷藏箱供电规则

- 每个贝位维护「插口总数」与「检修停用数」，可用插口 = 总数 − 停用；
- 自动配载/手动落箱只把冷箱放到「有空插口贝位的 1—3 层」格位；
- 插口不足的冷箱进入**待供电队列**，按卸货港先后（同港按入队序）排队；
- 插口检修恢复或格位腾退后，队头自动补进可用低层格位，受影响箱位的占用立即失效重算；
- 未受影响箱沿用原结论，稳性力矩与规则校验按签名增量复用；
- 待供电队列未清空时，「定为最终方案（放行）」与「导出配载图（打印）」被拦截；
- 导出的配载清单 CSV 含每箱插口状态、贝位插口统计和待供电明细。
